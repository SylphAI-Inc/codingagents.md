## Where to find skills

Agents need procedures, not just tools. A skill is a `SKILL.md` file that teaches an agent how your team does a thing — and most agents have no registry of their own, so you bring your own.

**[@skills](/protocols/atskills/) is the universal standard and hub for agents to manage skills.** It works by path rather than by install, so any agent that reads files is already a client.
